# 微博与云文档自动同步助手 (Chrome 扩展版)

> **极简部署 · 免环境配置 · 所见即所发 · 复用自然会话 · 抗平台风控**

本插件将**「云文档待办提取 ➜ 微博自动化发布 ➜ 博文链接自动回填文档」**三大核心能力封装为标准的浏览器轻量扩展。针对跨设备部署、运营人员无痛上手而设计。

---

## 核心设计原则

1. **所见即所发**：点击【🔍 扫描文档】后，直观展开任务卡片列表，列出待发文案、账号与回写单元格，支持任意勾选/反选，彻底告别盲发恐惧；
2. **零环境门槛**：对方电脑**无需安装 Python**、无需下载任何浏览器内核驱动，发个压缩包加载即用；
3. **天然抗风控**：直接复用操作人日常打开的微博与文档 Cookie 会话，平台视为普通人工操作，杜绝异地登录滑块；
4. **安全演练兜底 (Dry-Run)**：默认开启演练模式，仅完成输入校验与模拟写回，绝不擅自向微博平台点击发送。

---

## 交付部署指南（30 秒完成）

1. **打包交付**：将 `weibo-post-sync-extension` 文件夹压缩为 `.zip` 发送给同事或使用者，解压至任意目录。
2. **打开扩展管理**：在 Chrome 或 Edge 浏览器地址栏输入：
   * Chrome 用户输入：`chrome://extensions/`
   * Edge 用户输入：`edge://extensions/`
3. **加载插件**：
   * 开启右上角 **“开发者模式” (Developer mode)**；
   * 点击左上角 **“加载已解压的扩展程序” (Load unpacked)**；
   * 选中解压出的 `weibo-post-sync-extension` 目录即可。

---

## 极简使用流程（两步闭环）

1. **步骤一：扫描核对**
   * 在浏览器标签页中打开你的**腾讯文档**或**钉钉表格**；
   * 点击插件右上角图标，点击 **【读取当前页】** 捕获链接；
   * 点击 **【🔍 扫描文档】**：界面将立即展示所有“有内容但链接列为空”的待发任务卡片；
   * 支持全选或勾选指定的几条，心里 100% 有底。
2. **步骤二：一键同步**
   * 保持默认的 **【🛡️ 安全演练模式】** 运行一次；
   * 确认演练回执准确后，关闭安全拨片切至实盘，点击 **【开始真实同步发布】**；
   * 列表卡片会实时打上绿色对勾 `✅ E12 已写回`，全部发布并写回完毕！
